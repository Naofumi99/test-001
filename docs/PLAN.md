## 0. この計画のゴール

- **作るもの**: チームで使える経費精算システム
- **最初の段階（今回）**: 「見た目だけ」＝フロントエンドのみ。
  ブラウザだけで動き、経費を入力・一覧・合計できる状態を目指します。
- **あとで（将来の段階）**: サーバーやログインを足して、
  本当に「チーム全員」で共有できるようにします。

> 💡 なぜ段階を分けるの？

> 一気に必要になり、初心者には難しすぎます。まず1人のブラウザで完成させ、
> 動く楽しさを味わってから、共有機能を足すのが挫折しないコツです。

## 1. 必要な開発環境（道具をそろえる）

このプロジェクトは **Cursor（エディタ）** と **GitHub（保存・共有）** で進めます。
最初の段階で必要なのは、これだけです。

| 道具 | 役割 | 補足 |
|------|------|------|
| **Cursor** | コードを書くエディタ（AI付き） | 無料で始められる。VS Code がベースなので操作は同じ。AIに質問しながら書ける |
| **GitHub アカウント** | コードの保存・共有・公開の置き場所 | 無料。`Naofumi99/test-001` を使用中 |
| **Git** | 変更を記録する仕組み | Cursor の中から画面クリックで操作できる |
| **Google Chrome** | 動きを確認するブラウザ | 普段使っているものでOK |

> 💡 Cursor は「AI付きのVS Code」です。
> 画面の見た目や操作はVS Codeと同じで、さらに `Cmd/Ctrl + L` でAIに
> 「この行の意味を教えて」「エラーの直し方は？」と日本語で聞けます。
> 初心者ほど心強い相棒になります。

**この段階では不要なもの**（安心してください）:
- ❌ Node.js（サーバー用。将来の段階で使います）
- ❌ npm やビルドツール（設定が複雑なので後回し）
- ❌ データベース（将来の段階で使います）

**あると便利（任意）**:
- Cursor 拡張機能「**Live Server**」（VS Code と同じものが使えます）
  → ファイルを保存すると自動でブラウザが更新される。あると開発が快適です。

## 2.5 GitHub を使った進め方（保存と共有の流れ）

Cursor で書いたコードは、GitHub に「アップロード」して保存・共有します。
毎回この3ステップを繰り返すだけです（Cursor の画面ボタンでできます）。

1. **コミット（commit）** = 変更に名前を付けて記録する（例:「フォームを追加」）
2. **プッシュ（push）** = 記録を GitHub にアップロードする
3. GitHub 上で、いつ・何を変えたかが履歴として残る

```
[Cursor で編集]  →  コミット（記録）  →  プッシュ（GitHubへ）
      ↑______________ 必要ならいつでも過去の状態に戻せる ______________|
```

> 💡 GitHub のうれしい点
> - 万一PCが壊れても、コードは GitHub に残る（バックアップ）
> - 「昨日の状態に戻したい」がボタン1つでできる
> - 後の段階で **GitHub Pages** を使うと、作った画面をネットに無料公開でき、
>   チームの人にURLを送って見てもらえます（※データ共有はまだ。見た目の共有だけ）

## 3. 必要な機能（何ができれば「完成」か）

### 今回の段階でつくる機能（フロントエンドのみ）

1. **経費を入力するフォーム**
   - 日付 / 内容（例: タクシー代）/ 金額 / カテゴリ（交通費・飲食費など）/ メモ
2. **入力した経費を一覧表示**（表で下に並ぶ）
3. **合計金額の表示**（一覧の合計を自動計算）
4. **経費の削除**（間違えた行を消せる）
5. **ブラウザ内に保存**（localStorage を使い、閉じても消えないように）

### 今回はやらないこと（将来の段階に回す）

- 🔜 チーム全員での共有（サーバーが必要）
- 🔜 ログイン / 誰が申請したかの管理
- 🔜 「申請中 → 承認 → 却下」の承認フロー
- 🔜 CSV出力、レシート画像の添付、月ごとの集計グラフ

> ⚠️ 大事な前提
> 今回の段階では、データは「あなたのブラウザの中」だけに保存されます。
> 別のPCや他の人からは見えません。それでOK、まず動くものを作るのが目的です。
> 共有は将来の段階で足します。

## 4. 開発手順（小さなステップに分解）

1つのステップは「1回で終わる小さな作業」にしています。
各ステップは、**実行前に「これから何をするか」を説明してから**進めます。

| ステップ | やること | 使う技術 |
|---------|---------|---------|
| **Step 0** | 環境の準備（Cursor・Chrome の用意、GitHub アカウント確認） | 準備のみ |
| **Step 1** | GitHub のこのプロジェクトを Cursor に取り込む（クローン） | Cursor / GitHub |
| **Step 2** | フォルダと空ファイルを作る（index.html, css, js） | ファイル作成 |
| **Step 3** | 画面の骨組みだけ作る（タイトルを表示） | HTML |
| **Step 4** | 入力フォームを作る（日付・金額などの欄） | HTML |
| **Step 5** | 見た目を整える（色・余白・表の線） | CSS |
| **Step 6** | 「追加」ボタンで一覧に表示できるようにする | JavaScript |
| **Step 7** | 合計金額を自動で計算して表示 | JavaScript |
| **Step 8** | 「削除」ボタンで行を消せるようにする | JavaScript |
| **Step 9** | ブラウザに保存して、閉じても消えないようにする | JavaScript |
| **Step 10** | 全体を見直して見た目・使いやすさを改善 | HTML/CSS |

> 各ステップの区切りで、Cursor から **コミット→プッシュ** して GitHub に保存します。

**将来の段階（今回の後）**:
