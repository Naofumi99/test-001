# 経費精算システム 開発計画（初心者向け）

このドキュメントは「何を・どの順番で・どうやって作るか」を整理したものです。
**まだコードは書きません。** これは地図です。1ステップずつ、実行前に必ず説明します。

---

## 0. この計画のゴール

- **作るもの**: チームで使える経費精算システム
- **最初の段階（今回）**: 「見た目だけ」＝フロントエンドのみ。
  ブラウザだけで動き、経費を入力・一覧・合計できる状態を目指します。
- **あとで（将来の段階）**: サーバーやログインを足して、
  本当に「チーム全員」で共有できるようにします。

> 💡 なぜ段階を分けるの？
> 「チーム全員で共有」を最初からやると、サーバー・データベース・ログインが
> 一気に必要になり、初心者には難しすぎます。まず1人のブラウザで完成させ、
> 動く楽しさを味わってから、共有機能を足すのが挫折しないコツです。

---

## 1. 必要な開発環境（道具をそろえる）

最初の段階で必要なのは、たったこれだけです。

| 道具 | 役割 | 補足 |
|------|------|------|
| **VS Code** | コードを書くエディタ | 無料。Microsoft製。初心者の定番 |
| **Google Chrome** | 動きを確認するブラウザ | 普段使っているものでOK |
| **Git / GitHub** | 変更の記録と保存 | このプロジェクトは設定済み |

**この段階では不要なもの**（安心してください）:
- ❌ Node.js（サーバー用。将来の段階で使います）
- ❌ npm やビルドツール（設定が複雑なので後回し）
- ❌ データベース（将来の段階で使います）

**あると便利（任意）**:
- VS Code 拡張機能「**Live Server**」
  → ファイルを保存すると自動でブラウザが更新される。あると開発が快適です。

## 2. フォルダ構成（ファイルの置き場所）

最終的にこうなる予定、という完成イメージです。
今は空っぽで、ステップごとに1つずつ作っていきます。

```
test-001/
├─ README.md          … プロジェクトの説明
├─ index.html         … 画面そのもの（骨組み）
├─ css/
│   └─ style.css      … 見た目・デザイン（色や配置）
├─ js/
│   └─ app.js         … 動き（ボタンを押したら追加される等）
└─ docs/
    └─ PLAN.md        … この計画書
```

> 💡 3つの役割分担を覚えると理解が早いです。
> - **HTML** = 骨組み（何があるか）
> - **CSS**  = 見た目（どう見えるか）
> - **JavaScript** = 動き（押したら何が起きるか）

## 3. 必要な機能（何ができれば「完成」か）

### 今回の段階でつくる機能（フロントエンドのみ）

1. **経費を入力するフォーム**
   - 日付 / 内容（例: タクシー代）/ 金額 / カテゴリ（交通費・飲食費など）/ メモ
2. **入力した経費を一覧表示**（表で下に並ぶ）
3. **合計金額の表示**（一覧の合計を自動計算）
4. **経費の削除**（間違えた行を消せる）
5. **ブラウザ内に保存**（localStorage を使い、閉じても消えないように）

### 今回はやらないこと（将来の段階に回す）

- 🔜 チーム全員での共有（サーバーが必要）
- 🔜 ログイン / 誰が申請したかの管理
- 🔜 「申請中 → 承認 → 却下」の承認フロー
- 🔜 CSV出力、レシート画像の添付、月ごとの集計グラフ

> ⚠️ 大事な前提
> 今回の段階では、データは「あなたのブラウザの中」だけに保存されます。
> 別のPCや他の人からは見えません。それでOK、まず動くものを作るのが目的です。
> 共有は将来の段階で足します。

## 4. 開発手順（小さなステップに分解）

1つのステップは「1回で終わる小さな作業」にしています。
各ステップは、**実行前に「これから何をするか」を説明してから**進めます。

| ステップ | やること | 使う技術 |
|---------|---------|---------|
| **Step 0** | 環境の準備（VS Code・Chrome・Live Server の確認） | 準備のみ |
| **Step 1** | フォルダと空ファイルを作る（index.html, css, js） | フォルダ作成 |
| **Step 2** | 画面の骨組みだけ作る（タイトルを表示） | HTML |
| **Step 3** | 入力フォームを作る（日付・金額などの欄） | HTML |
| **Step 4** | 見た目を整える（色・余白・表の線） | CSS |
| **Step 5** | 「追加」ボタンで一覧に表示できるようにする | JavaScript |
| **Step 6** | 合計金額を自動で計算して表示 | JavaScript |
| **Step 7** | 「削除」ボタンで行を消せるようにする | JavaScript |
| **Step 8** | ブラウザに保存して、閉じても消えないようにする | JavaScript |
| **Step 9** | 全体を見直して見た目・使いやすさを改善 | HTML/CSS |

**将来の段階（今回の後）**:
- Step 10〜: サーバー（Node.js など）を足す
- Step 11〜: データベースに保存する
- Step 12〜: ログインとチーム共有を足す

---

## 5. 各ステップの進め方（ルール）

1. ステップを始める前に、**「今から何をするか」「なぜするか」** を説明します。
2. コードには **日本語のコメント** を入れて、後で読み返せるようにします。
3. 1ステップ終わるごとに **ブラウザで動きを確認** します。
4. うまく動いたら **Git で記録（コミット）** して、いつでも戻れるようにします。
5. わからない用語が出たら、遠慮なく質問してください。都度かみ砕いて説明します。
